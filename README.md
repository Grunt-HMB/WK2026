# WK 2026 Pronostiek

## Upload naar GitHub

1. Maak nieuwe repository op GitHub
2. Upload alle bestanden uit deze ZIP
3. Push naar GitHub

## Deploy naar Streamlit

Ga naar:
https://share.streamlit.io

Klik:
- Create app
- Kies je repository
- Main file: app.py

## Google Sheets

Maak tabs:
- Users
- Matches
- Predictions
- Results

## Start lokaal

streamlit run app.py
